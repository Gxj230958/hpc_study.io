# HPC Study

Start with a correct result, then measure how a machine executes it. This course takes you from CPU and memory behavior through CUDA, MPI and distributed training to an analytical study of datacenter GPUs.

1. Complete [setup](learning/setup.md), choosing the CPU or GPU environment.
2. Run [machine fundamentals](hardware/hardware-intro.md), beginning with the ten-minute inventory.
3. Follow the [eight-module course map](learning/path.md) and keep a notebook of commands, correctness checks and measurements.

The course assumes basic programming and shell experience. A conventional 24 GB RTX 4090 is sufficient for the single-GPU path; CPU-only lessons need no GPU. A second GPU or node is needed only for the explicitly marked distributed extensions. The datacenter module is a sourced analysis exercise, not an A100/H100/H200 hardware lab.

[Experiments](learning/labs.md) lists all 24 tasks. [Validation](learning/validation.md) distinguishes executed checks, historical results, calculated bounds and unexecuted hardware configurations.

[Download runnable examples](/hpc_study.io/downloads/hpc-study-examples.zip), including the uv lockfile and instructions, or consult the [frozen Chinese archive](/hpc_study.io/archive/zh/).

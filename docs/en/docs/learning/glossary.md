# Chinese-English Glossary

**Prerequisites:** None beyond basic programming. **Objective:** Connect terminology in the frozen archive with the English course.

| English | Chinese | Meaning |
| --- | --- | --- |
| core | 核心 | Hardware execution resource on a CPU or GPU |
| process | 进程 | Execution context with its own address space |
| thread | 线程 | Execution stream sharing a process's memory |
| rank | 秩 / 进程编号 | Process identifier within an MPI communicator |
| cache line | 缓存行 | Unit transferred between cache levels |
| locality | 局部性 | Reuse of nearby data or recently accessed data |
| bandwidth | 带宽 | Bytes transferred per second across a stated boundary |
| latency | 延迟 | Time to complete one stated operation |
| reduction | 归约 | Combining partial values with an operation such as sum |
| collective | 集合通信 | Coordinated operation involving a process group |
| residual | 残差 | Difference between an equation's two sides at a candidate solution |
| arithmetic intensity | 算术强度 | Useful FLOPs per byte at a stated memory boundary |
| strong scaling | 强扩展 | Fixed total work with more workers |
| weak scaling | 弱扩展 | Fixed work per worker with more workers |
| scheduler | 调度器 | Service assigning jobs to resources |
| rendezvous | 会合 | Process discovery and membership setup |
| oversubscription | 超额订阅 | More runnable workers than allocated execution capacity |
| mixed precision | 混合精度 | Combining number formats in a computation |

# Experiment Inventory

There are eight assessed modules and 24 experiments. Each has a ten-minute warm-up, twenty-minute core and thirty-minute stretch. Times include interpretation, and source programs remain deliberately small.

All Answer explanations are closed until opened. Local executability describes the primary hardware configuration, not whether a fallback exists. A passed fallback does not validate unavailable hardware. Datacenter exercises are analysis; their optional CPU calculator does not execute A100/H100/H200 work.

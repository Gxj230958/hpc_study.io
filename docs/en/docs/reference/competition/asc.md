**Prerequisites:** [Competition overview](competition-intro.md). **Objective:** Connect application tuning to correctness evidence.

Competition preparation benefits from a measured baseline, source control for changes and independent numerical checks. Record assumptions about input size, precision and resource limits before tuning.

Consult the [ASC organizer](https://www.asc-events.org/) for current rules, tasks and eligibility. The course does not infer this year's configuration from older editions.

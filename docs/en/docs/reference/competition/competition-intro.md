# HPC Competitions

**Prerequisites:** [Benchmark design](../../benchmark/intro.md). **Objective:** Treat a contest as a constrained engineering problem.

Student cluster competitions combine application correctness, performance, hardware operation and resource constraints. Power, budget and permitted configurations can matter as much as kernel speed.

Build a reproducible baseline before tuning. Keep inputs, build flags, licenses, validation output and machine allocation with each result. A failed correctness check disqualifies a fast result.

Rules and schedules change, so obtain the current organizer's handbook rather than relying on archived descriptions. Next, compare [SC](sc.md), [ISC](isc.md) and [ASC](asc.md).

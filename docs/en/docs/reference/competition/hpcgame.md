# HPCGame

**Prerequisites:** Basic shell and programming. **Objective:** Use small challenges to practice reproducible optimization.

A focused optimization task can isolate indexing, memory locality, parallel partitioning or numerical accuracy. First reproduce the reference answer and measurement procedure; then propose a hypothesis and test it.

Keep every tested variant and disclose compiler flags, hardware and input size. Avoid fitting an optimization only to a visible tiny example without testing boundaries.

Consult the [HPCGame project](https://github.com/hpcgame) for event-specific materials. Next, try the [CPU parallelism experiments](../../parallel-programming/parallel-programming-intro.md).

# ISC Student Cluster Competition

**Prerequisites:** [Competition overview](competition-intro.md). **Objective:** Plan repeatable application experiments.

Treat application installation, configuration, validation and measurement as separate steps. Preserve a known-correct baseline and change one variable per comparison.

Use [ISC's official site](https://isc-hpc.com/) to locate the current event and competition rules. Historical event descriptions in the Chinese archive remain historical.

Next, study [cluster software modules](../../clusters/modules.md) to make application environments reproducible.

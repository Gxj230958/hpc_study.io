# SC Student Cluster Competition

**Prerequisites:** [Competition overview](competition-intro.md). **Objective:** Identify preparation that remains useful across editions.

Prepare reproducible application builds, numerical validation and power-aware measurement. Practice team handoffs and recovery from a failed run; unattended scripts should retain outputs and return nonzero on failure.

Edition-specific eligibility, workloads and power limits must come from the [SC Student Cluster Competition](https://www.studentclustercompetition.us/) organizer. No current schedule or fixed limit is asserted here.

Next, practice [measurement](../../performance-analysis/intro.md) with an explicit resource budget.

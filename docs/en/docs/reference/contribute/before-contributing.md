# Contributing

**Prerequisites:** Git and the course setup. **Objective:** Make a reviewable correction.

State the concrete problem and affected behavior. Preserve author attribution, CC BY-NC-SA 4.0 terms and separate vendor licenses. Frozen Chinese sources should remain unchanged; English corrections belong in docs/en/docs.

For a new lab, update course/labs.json and its lesson together. Include bounded commands, independent correctness checks, failure modes, cleanup and a closed Answer explanation. Hardware you cannot access must remain unexecuted in validation metadata.

Run the strict two-site build and relevant checks before proposing a change. Next, follow [organization](docs-organization.md) and [style](docs-style.md).

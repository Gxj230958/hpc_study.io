# Writing Conventions

**Prerequisites:** [Organization](docs-organization.md). **Objective:** Write a lesson a beginner can execute.

Define a term before relying on it. State prerequisites, hardware assumptions, learning objectives and next steps. Explain what a command verifies and what a successful output cannot establish.

Use exact commands from the repository root and bounded input sizes. Provide a reference answer in a closed details block using ??? success "Answer". Distinguish observed measurements, calculated limits, historical results and unexecuted configurations.

Keep links and heading anchors stable when feasible; document migration exceptions and link original context. Next, inspect the [experiment inventory](../../learning/labs.md).

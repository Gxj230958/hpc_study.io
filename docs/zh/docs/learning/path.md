# 从这里开始：HPC 学习路线

你不需要一开始就有集群。本课程从一台普通 Linux 电脑出发，逐步学习并行程序，再进入 GPU 和科学计算。

## 开始前需要什么

能在终端运行命令，能读懂变量、循环、数组与函数即可。C/C++ 不熟悉时，可以先运行 Python 实验，再对照阅读短 C 示例。数学部分遇到新符号会解释含义，不要求先学完数值分析。

先完成[环境准备](setup.md)。所有源码保存在仓库的 `examples/`，命令默认从仓库根目录执行。网站中的短片段用于讲解，完整运行入口见[实验索引](labs.md)。

## 五个阶段

| 阶段 | 先读 | 完成后应能做到 |
| --- | --- | --- |
| 1. 认识机器 | [硬件](../hardware/hardware-intro.md) | 解释容量、带宽与延迟，读懂自己的资源限制 |
| 2. 分工合作 | [执行模型](../thread-process/intro.md)、[OpenMP](../parallel-programming/openmp.md)、[MPI](../parallel-programming/mpi.md) | 划分数组，正确归约，识别竞争与等待 |
| 3. 使用 GPU | [GPU 导论](../gpu/intro.md)、[架构](../gpu/arch.md)、[CUDA](../gpu/cuda.md) | 写出有边界检查的 kernel，并验证输出 |
| 4. 学会测量 | [Benchmark](../benchmark/intro.md) | 固定条件、同步计时、记录重复测量 |
| 5. 连接应用 | [科学计算与机器学习](../sci-mlsys/intro.md) | 使用数值库，理解训练、误差和数据流 |

每个阶段预留数小时阅读和实验。实际时间取决于基础，不必为了赶进度跳过结果检查。

## 没有 GPU 的路径

完成全部硬件、CPU 并行、单机 MPI、稀疏求解和量化实验。GPU 部分先画线程下标、内存流向与矩阵边界。等有设备后，再编译运行 CUDA。多卡 NCCL 与 AMD HIP 是设备相关选读，不影响主线学习。

## 学习时保留一份记录

每次实验写下：原来的猜想、命令、输入、原始输出、结果解释。如果结果和猜想不同，先检查输入和计时，再考虑硬件因素。一次实验不够支持“某技术总是更快”的结论。

找不到术语时查看[术语表](glossary.md)。需要检查本课程实际跑过哪些实验时，查看[验证记录](validation.md)。

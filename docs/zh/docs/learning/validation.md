# 课程验证记录

本页说明教材代码的验证范围。原始记录与复现入口保存在仓库中。性能数据只适用于记录的环境与输入，不能代表所有同型号硬件。

## 本次环境

验证日期为 2026-09-21，Linux x86-64，Python 3.10，GCC、MPICH 与 OpenBLAS。容器 CPU 配额为 10 个 CPU 当量，内存上限 100 GiB。普通检查使用 4 个线程，线程对照最多使用 8 个。

设备报告为一张 NVIDIA GeForce RTX 4090，计算能力 8.9，驱动 550.163.01。CUDA Toolkit 为 12.4.1，PyTorch 为 2.6.0+cu124。此设备报告显存 49140 MiB，这是本机观察值，不是标准零售 4090 的规格。

## 已执行的检查

`python scripts/validate.py --gpu` 共执行 **40 项检查，全部通过**。其中非法输入检查预期返回退出码 2；其余检查退出码为 0。检查按环境文档执行。汇总同时记录运行开始时的源码哈希，运行结束时再次核对源码未变。

| 项目 | 实际范围 | 判定 |
| --- | --- | --- |
| OpenMP | 1、2、4、8 线程，3 种长度，另测非法输入 | 与解析整数和一致 |
| MPI | 1 至 4 进程；空输入、小于进程数、不均匀分块 | 求和正确；往返消息内容正确 |
| 数值计算 | 127 阶三对角系统 | CG 收敛，残差和稠密解对照通过 |
| 量化 | 固定种子合成权重，INT8 表示与还原 | 误差满足半步长附近的界限 |
| CUDA | 向量长度 1、255、256、257、100003；矩阵阶数 1、15、16、17、65 | CPU 参考检查通过 |
| CUDA 检查器 | memcheck、synccheck、racecheck | 未报告错误 |
| PyTorch | CPU 与单 GPU 合成线性回归；512 阶 FP32／FP16 矩阵乘法 | 前向、损失下降和数值误差检查通过 |
| HPL／HPCG | 官方实现、单 MPI 进程、微型输入与短时间运行 | HPL 残差检查通过；HPCG 数值检查有效 |
| 网页 | 桌面 1440×1000、手机 390×844，各检查 7 个代表页面 | 搜索、下载、图示、公式、主题与导航检查通过 |

HPL、HPCG 和网页检查分别执行，不计入上述 40 项。Nsight Systems 另行采集了三个 CUDA kernel 及传输活动，分析工具会影响耗时，不与无分析器运行混为同一组性能数据。

## 这些结果不能说明什么

短跑只验证安装、数值与流程。HPCG 本次运行远短于正式规则所需时间，输入也很小；HPL 同样使用教学规模。它们不是正式提交成绩，也不能代表整机极限性能。

合成训练例子没有真实任务的测试集，不证明模型泛化能力。量化例子是表示误差实验，不是 INT8 推理加速测试。固定种子的单次教学验证不等于多种数据集上的系统评测。

未执行多 GPU NCCL、多节点通信、AMD HIP、OpenCL 设备路径、NVIDIA OpenACC 卸载或正式 MLPerf 任务。相关章节给出概念与环境要求，不宣称已经实测。请在自己的机器上重新测量，并保留原始结果。
